# Hi, I'm Ivelin Panchev

**Software Developer · Vue.js and TypeScript · Sofia, Bulgaria**

I build web interfaces and work on the Java APIs behind enterprise applications. My main focus is frontend development: reusable Vue components, responsive layouts, real-time interactions and practical UI design.

I've worked at **Devalex Consulting since 2023**, developing company products and contributing to an enterprise client assignment for **Sunrise**.

## Professional work

- **Frisbee:** primary frontend ownership of a workforce-management admin application. Built account and task workflows, live maps, reporting, and group and direct chat using GraphQL subscriptions over WebSockets.
- **Devalex website:** implemented the official company website from designers' Figma files with Vue 3, TypeScript and reusable responsive components.
- **Sunrise, through Devalex:** implement Java API endpoints and business validation, SQL-backed statistics and Sencha Ext JS interfaces. Work with REST/SOAP services, API documentation and release validation in an English-speaking team.

Most of my professional work is in private employer repositories. My public repositories include academic and personal projects.
